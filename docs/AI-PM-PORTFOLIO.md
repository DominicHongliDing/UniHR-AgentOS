# 丁泓力 · 产品与项目

我正在思考怎样把 AI 工具用到高校行政中，也在围绕查政策、整理材料和制作文件做具体尝试。本科在西交利物浦大学学习生物信息学，硕士在康奈尔大学学习医疗信息学与人工智能，正在寻找 AI 产品经理与 FDE 方向的机会。

## 需求来源与参与

目前我在浙江大学“一带一路”国际医学院从事人事与国际交流工作，也参与 AI 业务流程优化。UniHR 来自这些工作及与经办同事的交流；Clinical 来自在卡罗莱纳精神病研究所实习、参与 VedAI 时接触到的使用反馈；EVO 来自迭代前两个项目时比较修改效果的需要。

实习期间，我与项目负责人、精神科医生及前后端工程师沟通，参与 VedAI 的需求研究、原型验证与上线。Clinical Agent 是之后的个人项目。在个人项目中，我负责需求、范围、交互和验收要求，并借助 AI 编程工具实现原型。
